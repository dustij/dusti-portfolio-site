## Overview

Mentor Data Table is built for repeated data review. Instead of presenting
records as static output, the app gives users the controls they need to find a
session, compare records, and export the current data set.

The core interface is intentionally practical. Search, filter, sort, and export
are treated as first-class actions because those are the workflows that make the
data useful.
