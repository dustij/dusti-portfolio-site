## Overview

Reed-Solomon encoding is easier to talk about when the intermediate state is
visible. This desktop application turns the algorithm into a GUI-driven demo so
users can follow how data is encoded, how errors are introduced, and how
decoding recovers the original message.

The project was presented at Washburn University’s Apeiron event, which shaped
the interface requirements. It needed to be understandable in a live setting,
not just correct in code.
