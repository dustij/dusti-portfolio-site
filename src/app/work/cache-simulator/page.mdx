## Overview

Cache behavior is easier to understand when the state is visible. This project
lets users explore direct-mapped, fully-associative, and set-associative caches
by adjusting inputs and observing how addresses land in cache lines or sets.

The interface is designed as a learning tool: it keeps the cache configuration,
memory references, and resulting state close together so users can connect each
step with the outcome.
