## Overview

The Mesocycle Workout Planner is a recent TypeScript project for organizing
training blocks. The goal is to make workout planning more structured than a
loose note while still keeping the interface flexible enough for revisions.

Because training plans change over time, the application needs to make the
current plan readable and editable. The useful part of the interface is not just
capturing data, but helping the user understand how a block is organized.
